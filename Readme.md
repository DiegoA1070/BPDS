## Descripción de proyecto
Este proyecto es realizado con el fin de aplicar buenas practicas durante el desarrollo y organización de un proyecto de software, utilizando herramientas como HTML, CSS, JavaScript y GIT.

Lo primero que aprendí fue a manejar lo que es GIT y algunos de sus comandos como por ejemplo:

| Comando | Función | Ejemplo |
 |---|---|---| 
 | `pwd` | Muestra el directorio actual | `pwd` |
 | `ls` | Muestra los archivos y carpetas | `ls` |
 | `cd` | Cambia de directorio | `cd CRUD` |
 | `cd ..` | Regresa al directorio anterior | `cd ..` | 
 | `mkdir` | Crea una carpeta | `mkdir CRUD` |
 | `touch` | Crea un archivo | `touch README.md` | 
 | `rm` | Elimina un archivo | `rm archivo.txt` |
 | `clear` | Limpia la terminal | `clear` | 
 | `git init` | Inicializa un repositorio Git | `git init` |
 | `git status` | Muestra el estado del repositorio | `git status` | 
 | `git add` | Agrega cambios al área de preparación | `git add .` | 
 | `git commit` | Guarda los cambios en Git o toma una foto | `git commit -m "Primer commit"` | 
 | `git log` | Muestra el historial de commits | `git log` |
 | `git branch` | Muestra las ramas existentes | `git branch` |
 | `git checkout` | Cambia de rama | `git checkout main` | 
 | `git checkout -b` | Crea y cambia a una nueva rama | `git checkout -b feature/readme` |
 | `git pull` | Descarga y combina cambios del remoto | `git pull origin main` | 
| `git clone` | Clona un repositorio remoto | `git clone URL` |
| `git fetch` | Descarga cambios sin combinarlos | `git fetch` |
| `git remote add origin` | Conecta el repositorio local con GitHub | `git remote add origin URL` |

Gracias a estos comandos se trabajo un repositorio local y remoto en GitHub, aplicando conceptos como commits, ramas, integración de cambios y control de versiones. Permitiendo un desarrollo organizado.
